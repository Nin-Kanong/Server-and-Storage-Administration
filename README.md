# About This Repository

This repository contains step-by-step documentation for building and
managing a Windows Server environment.

The walkthrough begins with basic Windows Server deployment and gradually
moves into enterprise infrastructure concepts such as:

- Active Directory Domain Services
- Domain Controllers
- Users and Groups
- AD Delegation
- Recycle Bin
- File Screening
- Disk Quotas
- RAID
- Storage Pools
- File Sharing
- Group Policy
- GPO Loopback Processing
- User Configuration
- Desktop Management
