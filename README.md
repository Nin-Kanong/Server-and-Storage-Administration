# Windows Server & Active Directory Lab

This repository documents my hands-on learning and practical implementation
of **Windows Server administration, Active Directory, Group Policy, storage,
file services, and infrastructure security**.

The goal is to build practical skills that can be applied in:

- IT Infrastructure
- System Administration
- Windows Server Administration
- Active Directory Administration
- IT Security
- Security Engineering
- Infrastructure Security
- SOC / Blue Team environments

# About This Repository

This repository contains step-by-step documentation for building and
managing a Windows Server environment.

The walkthrough begins with basic Windows Server deployment and gradually
moves into enterprise infrastructure concepts such as:

- Active Directory Domain Services
- Domain Controllers
- Users and Groups
- AD Delegation
- Recycle Bin
- File Screening
- Disk Quotas
- RAID
- Storage Pools
- File Sharing
- Group Policy
- GPO Loopback Processing
- User Configuration
- Desktop Management

---

# Learning Objectives

The main objectives of this project are to develop practical experience with:

### Windows Server

- Windows Server installation
- Server configuration
- Server roles and features
- File and storage management

### Active Directory

- Domain Controller deployment
- AD DS configuration
- User management
- Group management
- Organizational structure
- Delegation

### Group Policy

- GPO creation
- User configuration
- Computer configuration
- Loopback processing
- Screen saver policies
- Desktop configuration

### Storage

- RAID configurations
- Storage Pools
- Volumes
- File shares
- Disk quotas
- File screening

### Security

- Least privilege
- Access control
- Delegation
- Centralized policy enforcement
- Account management
- Infrastructure hardening
