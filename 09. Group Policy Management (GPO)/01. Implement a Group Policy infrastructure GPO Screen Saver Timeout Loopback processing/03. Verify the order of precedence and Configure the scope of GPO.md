##### What this policy means
| **Setting**      | **Explanation**                                                                                                             |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Enabled**      | The Screen Saver Timeout policy is active. Windows will automatically start the screen saver after the specified idle time. |
| **7200 seconds** | The screen saver will start after **7,200 seconds**, which equals **2 hours** of inactivity.                                |

##### Time conversion
| **Seconds** | **Minutes** | **Hours** |
| ----------- | ----------: | --------: |
| 300         |           5 |      0.08 |
| 600         |          10 |      0.17 |
| 900         |          15 |      0.25 |
| 1800        |          30 |       0.5 |
| 3600        |          60 |         1 |
| **7200**    |     **120** |     **2** |

#### Loopback Processing Modes
| **Mode**    | **Meaning**                                                                                                                                            | **When to Use**                                                                                                                            |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Merge**   | Windows applies the user's normal GPOs first, then adds the user settings from the computer's OU. If there is a conflict, the computer's settings win. | Shared office computers, classrooms, or labs where users keep most of their own settings but the computer also enforces specific policies. |
| **Replace** | Windows ignores the user's normal User Configuration GPOs and applies **only** the user settings linked to the computer's OU.                          | Kiosks, reception desks, public PCs, exam rooms, or training labs where every user should have the exact same settings.                    |
