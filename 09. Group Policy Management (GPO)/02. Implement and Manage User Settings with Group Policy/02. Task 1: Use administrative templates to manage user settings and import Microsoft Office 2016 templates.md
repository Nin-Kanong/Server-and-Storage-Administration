<h1 align="center"> Task 1: Use administrative templates to manage user settings and import Microsoft Office 2016 templates </h1>


---

## Scenario  
A. Datum Corporation has implemented Microsoft Office 2016. You need to use Group Policy to configure settings for some Office 2016 apps.

### Background and problem  
The IT department currently uses logon scripts to provide users with drive mappings to shared folders. Maintaining these scripts is an ongoing problem because they are large and complex. Your manager has asked you to replace the logon scripts by implementing drive mappings with Group Policy Preferences.

### Requirements
1. **Replace logon-script drive mappings** with Group Policy Preferences drive mappings to remove the need for logon scripts.
2. **Deploy a desktop shortcut to Notepad** for all users who belong to the IT Security security group.
3. **Add a new computer administrators security group** as a local administrator on all servers.
4. **Configure Folder Redirection** to redirect several profile folders to each user’s home drive to help minimize profile sizes.
5. **Complete the GPO** design to manage user desktops and server security.
