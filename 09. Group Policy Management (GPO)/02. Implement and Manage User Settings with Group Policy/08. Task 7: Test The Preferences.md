| Member                     | Type         | Meaning                                                                                                                                                                                  |
| -------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Administrator**          | Local user   | The built-in local Administrator account created when Windows is installed. It always has full administrative privileges.                                                                |
| **CYBERSEC\Domain Admins** | Domain group | This is an Active Directory security group. Any user who belongs to the **Domain Admins** group automatically becomes a local administrator on all domain-joined computers (by default). |
| **k4n0ng**                 | User account | This user account has been added directly to the local Administrators group, so **k4n0ng** has administrator rights on this computer.                                                    |
