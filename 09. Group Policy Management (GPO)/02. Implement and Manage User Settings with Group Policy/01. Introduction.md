## Implement and Manage User Settings with Group Policy

**Implement and manage user settings with Group Policy** means creating and applying Group Policy Objects (GPOs) that control the Windows environment for users in an Active Directory domain. These settings are applied when a user logs in and help organizations enforce consistent configurations, improve security, and simplify administration.

To implement and manage user settings with Group Policy, follow these steps:
- **Create a GPO**: Use the Group Policy Management Console (GPMC) to create a new GPO by clicking on Action > New. Name the object and save it.
- **Link the GPO**: ``Right-click`` on the location where we want to link the GPO and choose Link an Existing GPO. Alternatively, we can create a GPO in this domain and link it here.
- Configure the GPO: Define the settings we want to apply to the linked segment of our AD. This includes setting up user-specific configurations like Internet Explorer settings and Folder Redirection.
- Apply the GPO: Once the GPO is created and linked, it will be applied to users when they log in, ensuring consistent configurations across the organization. 
- By following these steps, organizations can effectively manage user settings and enforce consistent configurations, improving security and simplifying administration.


## What is Group Policy?
**Group Policy** is a feature in **Active Directory Domain Services (AD DS)** that allows administrators to centrally configure and manage Windows computers and users.

Instead of configuring each PC manually, you create a policy once on the **Domain Controller**, and it is automatically applied to all targeted users or computers.

## What are User Settings?

User settings affect the user account, not the computer.

For example, if Alice signs into any company computer, her user settings follow her (unless overridden by special policies like loopback processing).

ser settings include:
- Desktop wallpaper
- Screen saver
- Start Menu
- Taskbar
- Control Panel access
- Network drives
- Printers
- Internet Explorer/Edge policies
- Login scripts
- Folder Redirection


## User Configuration vs Computer Configuration
| User Configuration          | Computer Configuration            |
| --------------------------- | --------------------------------- |
| Applies to users            | Applies to computers              |
| Processed during user logon | Processed during computer startup |
| Follows the user            | Stays with the computer           |
| Desktop settings            | Firewall settings                 |
| Wallpaper                   | Windows Updates                   |
| Start Menu                  | BitLocker                         |
| Drive mappings              | Network settings                  |
