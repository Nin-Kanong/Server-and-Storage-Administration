## Group Policy

| **Group Policy Feature**              | **Explanation**                                                                                                                                                           | **Purpose**                                                                                                                                     |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Group Policy Infrastructure (GPO)** | A Group Policy Object (GPO) is a collection of settings in Active Directory that administrators use to centrally manage users and computers.                              | Applies security settings, software, desktop configurations, and other policies across the domain.                                              |
| **Screen Saver Timeout**              | A policy that automatically starts the screen saver after the computer has been idle for a specified amount of time.                                                      | Improves security by preventing unauthorized access when a user leaves their computer unattended.                                               |
| **Loopback Processing**               | A Group Policy feature that applies **User Configuration** settings based on the **computer's OU** instead of the user's OU. It has two modes: **Merge** and **Replace**. | Ensures users receive the same desktop and security settings regardless of who logs on to a specific computer (e.g., kiosks, labs, shared PCs). |


Example:
| **Scenario**                       | **Without Loopback**                                   | **With Loopback**                                                                                                                  |
| ---------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| A student logs into a lab computer | The student receives policies from the **Student OU**. | The student receives the **Lab Computer's policies**, such as a fixed desktop, screen saver timeout, and restricted Control Panel. |


## Screen Saver Timeout
| **Policy**                    | **Value**                   | **Result**                                                                               |
| ----------------------------- | --------------------------- | ---------------------------------------------------------------------------------------- |
| Enable Screen Saver           | Enabled                     | The screen saver is turned on.                                                           |
| Screen Saver Timeout          | **300 seconds (5 minutes)** | The screen saver starts after 5 minutes of inactivity.                                   |
| Password Protect Screen Saver | Enabled                     | Users must enter their password to unlock the computer after the screen saver activates. |


## Loopback Processing Modes
| **Mode**    | **Description**                                                                                                                               |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Merge**   | User policies are applied first, then computer-based user policies are added. If there is a conflict, the computer's policy takes precedence. |
| **Replace** | User policies are ignored. Only the user settings linked to the computer's OU are applied.                                                    |
