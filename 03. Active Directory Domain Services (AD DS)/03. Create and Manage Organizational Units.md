In this we can use others.

Explaination:
| Option                                        | Meaning                                               | When to use                              |
| --------------------------------------------- | ----------------------------------------------------- | ---------------------------------------- |
| **Password**                                  | Enter the new user's password                         | User uses this to log in                 |
| **Confirm**                                   | Re-enter the same password                            | Verify password is correct               |
| **User must change password at next logon**  | User must create a new password when first logging in | Normal company security setting          |
| **User cannot change password**               | User is not allowed to modify password                | Service accounts or special accounts     |
| **Password never expires**                    | Password does not expire                              | Servers/service accounts (use carefully) |
| **Account is disabled**                       | User cannot login                                     | Temporary or future accounts             |



Example for company lab:
| User Type       | Settings                                          |
| --------------- | ------------------------------------------------- |
| HR Employee     | ✅ Must change password at next logon              |
| Normal User     | ✅ Must change password at next logon              |
| Admin Account   | Usually password never expires (lab only)         |
| Service Account | ✅ Password never expires + cannot change password |
| Disabled User   | ✅ Account disabled                                |
