Now I see this and I want to change to `k4n0ng`.

In this we can use with **CMD** and **PowerShell**:

- **CMD**:
````
wmic computersystem where name="%computername%" call rename name="k4n0ng"
````

- **PowerShell**:
````
Rename-Computer -NewName "k4n0ng" -Restart
````
